# Fonts

The interface uses Cerebri Sans, a licensed font. Put the licensed web font files here with exactly these names:

- `CerebriSans-Regular.woff2` (weight 400)
- `CerebriSans-Medium.woff2` (weight 500)
- `CerebriSans-SemiBold.woff2` (weight 600)

The files must cover Vietnamese (Cerebri Sans Pro does). Until they are present the interface falls back to the system sans-serif font.
